# Ember2D

Ember2D is a small, modular, Java-first 2D game framework built on libGDX, targeting desktop (Windows, Linux, macOS) and Android. It adds an opinionated integration layer and optional genre kits — platformer, top-down shooter, bullet hell, top-down RPG and visual novel — on top of proven tools such as Tiled, Ink and Scene2D, and is developed game-first: every engine feature is pulled in by a demo game that needs it.

All design and engineering documentation lives in [`documents/`](documents/README.md) — start with [`documents/README.md`](documents/README.md).
